# A Smooth Introduction to Scientific Machine Learning

Companion code for the edited volume *A Smooth Introduction to Scientific
Machine Learning: Mathematical Foundations and Numerical Implementation*,
edited by Victorita Dolean, Alexander Heinlein, and Olga Mula.

The book provides a mathematically grounded, hands-on introduction to
scientific machine learning (SciML). This repository collects reproducible
code, notebooks, and supporting data for its nine educational chapters.

> [!NOTE]
> The book and this repository are works in progress. APIs, examples, and
> directory contents may change before publication.

## Using the examples

Each chapter is self-contained. Start with its `README.md` for setup and
execution instructions. Python dependencies are listed in the
`requirements.txt` file within each chapter folder.

## Citation

Citation metadata for the companion repository is provided in
[`CITATION.cff`](CITATION.cff). GitHub can use this file to display a
**Cite this repository** link. Chapter-specific citation metadata is available
in each chapter folder.
